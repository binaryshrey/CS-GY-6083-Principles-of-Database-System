# Files

| File | What it contains |
|---|---|
| `README.md` | Setup, rebuild, running experiments, migrations, security measures, versions |
| `requirements.txt` | Pinned Python dependencies |
| `.env.example` | Settings template (API key, secret key, DSNs, optional tuning) |
| **sql/** | |
| `sql/01_schema.sql` | Part 2 table definitions, trigger, views and `llm_reader` role — unchanged |
| `sql/02_part3_migration.sql` | Part 3 additions: `app_user`, user questions, run owner, rewrite acceptance, effort, indexes, `v_run_rves`, `v_rewrite_outcome` |
| **t2s/** (pipeline package) | |
| `t2s/config.py` | Settings from the environment: DSNs, timing protocol, thresholds, model and effort |
| `t2s/db.py` | Results-database connection helpers (bound parameters only) |
| `t2s/targets.py` | Running SQL on the BIRD database: read-only `llm_reader` transaction, timeout, single statement; `EXPLAIN ANALYZE` timing; result comparison (set / multiset); schema-prompt builder |
| `t2s/plan_analysis.py` | Plan issue detection (`correlated_subplan`, `large_seq_scan`, `nested_loop_large`, `sort_spill`, `hash_spill`), cost fields, compact plan text for prompts, tables read |
| `t2s/llm.py` | Claude API call: structured JSON output `{sql, explanation}`, prompt caching of the schema, refusal fallback, token/latency accounting |
| `t2s/prompts.py` | Prompt text (version `p1`) for the initial, fix and rewrite stages |
| `t2s/pipeline.py` | The pipeline: write, fix loop, plan-guided rewrite loop with acceptance rule; stores a run's queries, plans, issues, timings and LLM calls in one transaction |
| `t2s/costs.py` | Spend cap: prices per model, logged + in-flight spend, check before every LLM call |
| `t2s/batch.py` | Creates an experiment's missing runs for a set of questions × configs × repeats |
| **scripts/** | |
| `scripts/load_bird.py` | Reproducible rebuild of both databases from the BIRD Mini-Dev zip, including gold timings |
| `scripts/create_user.py` | Trusted setup of accounts (the only way to create a researcher) |
| `scripts/run_experiment.py` | Batch runner (parallel LLM calls, serialized timing, resumable, optional freeze) |
| `scripts/eval_report.py` | Writes an experiment's evaluation tables and examples as Markdown |
| `scripts/export_dashboard.py` | Writes an experiment's report tables as JSON (rows + the SQL that made them) for the online dashboard |
| **webapp/** | |
| `webapp/app.py` | Flask app: sessions, CSRF, role checks, all routes (public, analyst, researcher), background execution of runs started from Ask / Questions |
| `webapp/queries.py` | Every SQL statement the web app runs, by name |
| `webapp/templates/base.html` | Layout and role-specific navigation |
| `webapp/templates/index.html` | Public home: purpose and available databases |
| `webapp/templates/login.html`, `register.html`, `goodbye.html`, `error.html` | Account pages and errors |
| `webapp/templates/home_analyst.html`, `home_researcher.html` | Role-specific home pages |
| `webapp/templates/ask.html` | Ask your own question |
| `webapp/templates/questions.html`, `question.html` | Browse / view benchmark questions; launch a run on one |
| `webapp/templates/runs.html`, `_runs_table.html`, `run.html` | Run history; one run's attempt chain, plans, timings, LLM calls |
| `webapp/templates/experiments.html`, `experiment.html` | Experiment list and read-only report |
| `webapp/static/style.css` | Styles |
| **docs/** | |
| `docs/FILES.md` | This list |

| `docs/evaluation_results.md` | Generated by `eval_report.py` after the main experiment |
| `docs/REFLECTION.md` | Evaluation write-up (after the main experiment) |
| **data/** (not submitted; recreated by the setup steps) | `minidev.zip`, extracted metadata, load log |
