Efficient Text-to-SQL

Ask a database a question in plain English and an AI model (Claude) writes the SQL. This system goes one step further than ordinary Text-to-SQL: it reads PostgreSQL's EXPLAIN ANALYZE plan of the generated query and asks the model for a faster query that returns exactly the same rows. A rewrite is kept only if the rows match and the measured runtime drops.

Every attempt, plan, timing and model call is stored, so we can measure accuracy against the BIRD benchmark's gold queries, speed (BIRD's R-VES score) and extra model cost.
